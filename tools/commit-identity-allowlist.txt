# Commit identities permitted in addition to the company identity.
#
# One `Name <email>` per line. Lines starting with '#' are comments.
#
# This exists for ONE reason: a pull-request check is run against a synthetic merge commit that
# the hosting platform creates and attributes to itself. That commit is an artefact of review, it
# belongs to no branch, and it cannot become part of the published history — the mirror publishes
# the branch, not the platform's refs. Auditing it reports the platform as a foreign identity and
# fails every pull request.
#
# This is deliberately narrow. The company identity is accepted by construction; everything else
# must be listed here, and adding a line is a reviewable act. In particular, no personal identity
# may ever appear here, because a personal identity CAN become part of the history and this list
# would silence exactly the check that catches it.
