# Secret-shaped values that are known test fixtures, not credentials.
#
# One extended regular expression per line. Lines starting with '#' are comments. A line in the
# secret scan's output that matches any pattern here is dropped before reporting.
#
# Why this exists: the secret scan matches a credential-ish key name followed by a long literal.
# A test that asserts the mutate gate refuses a wrong secret has to pass SOME secret to be a test
# at all, so a repository with a mutation gate will always have one of these. The alternative —
# renaming the constant until the scanner stops noticing — hides the value from review without
# making anything safer.
#
# A line belongs here only if the value is a literal whose only purpose is to be rejected by a
# test. Adding a line is a reviewable act: anything matched here is no longer reported, so a real
# credential that happened to match would be silenced.
