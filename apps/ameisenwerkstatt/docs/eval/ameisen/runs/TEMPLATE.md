# Eval run template (Ameisen tool façade)

Copy to `YYYY-MM-DD-<label>.md` before a sitting. Do not edit this template in place to record real
scores.

The model name lives here, as run metadata, and nowhere else. The goldens under
[`../goldens/`](../goldens/) stay blank.
