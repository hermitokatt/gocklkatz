# Tickets

One file per ticket: `NNN-short-slug.md`. Schema and rules:
[`FORMAT.md`](./FORMAT.md).

A ticket is the **frozen requirement**. It is written before implementation and
does not change afterwards — if the requirement was wrong, that is a new
ticket, not an edit. This is what stops a requirement from being retro-fitted
to whatever got built.

Tickets `001`–`005` are the frozen requirements that brought the landing page and the four demo
applications into this repository. They are kept as written and are not edited afterwards; where
later work changed a requirement, the change is a new ticket rather than a rewrite of an old one.

Work since then is tracked in **Linear** — project **Portfolio**, team **GOC** — and a Linear issue
is the frozen requirement for the change it describes. A ticket file is written here only when a
requirement needs to be frozen in the repository itself.
